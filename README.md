# Vibe Code Prompt · จากไอเดีย สู่ต้นแบบที่ใช้งานได้จริง

เครื่องมือช่วยสร้าง Prompt สำหรับคนที่เขียนโค้ดไม่เป็น ใช้ได้กับ AI ทุกตัว (Gemini · Claude · ChatGPT · Copilot)

- `index.html` — หน้าหลัก มี 2 แถบ: **สร้าง Prompt** และ **ตัวอย่างผลงาน**
- `examples/office-stretching.html` — ตัวอย่างผลงาน: แอปเตือนพักและพายืดเหยียดด้วยกล้อง (p5.js + ml5.js)

เว็บไซต์: https://ajnesttheseries.github.io/vibecodeprompt/
